# Images

Screenshots referenced by the project case studies.

## SpellType (`spelltype.html`)

Drop these three files here, then in `spelltype.html` replace the matching
`<div class="ph">…</div>` placeholder with the `<img>` tag shown in the
adjacent HTML comment.

| Filename | Shot |
|---|---|
| `spelltype-game.png` | Main game screen — word prompt + typing input |
| `spelltype-results.png` | Results / per-letter accuracy view after a round |
| `spelltype-leaderboard.png` | Leaderboard, public profile, or stats dashboard |

PNG preferred. Landscape orientation looks best with the case-study layout.
